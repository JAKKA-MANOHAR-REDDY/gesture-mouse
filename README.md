# GuesterMouseOnly

GuesterMouseOnly is a Python-based gesture mouse control app. It uses your camera to detect hand gestures and allows you to control the mouse without touching a physical mouse.

## Features

- Control mouse cursor using hand gestures
- Perform mouse clicks using finger gestures
- Scroll using hand movement
- Camera-based hand tracking
- Simple Python project structure
- Beginner-friendly setup

## Requirements

Before running this project, make sure you have:

- Python installed on your computer
- A working webcam or laptop camera
- Required Python packages installed from `requirements.txt`

## Installation

1. Download or clone this project.

2. Open the project folder.

3. Install the required packages:

pip install -r requirements.txt
